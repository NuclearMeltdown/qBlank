Download und Installation

Eine Datei, kein Installer. Eine Minute vom Download bis zum ersten Bild.

Download Was du brauchst Wohin damit SmartScreen Erste Schritte Updates Umzug von CapView Entfernen

Download

qBlank ist eine einzige qBlank.exe von etwa 3 MB.

Neueste Version herunterladen
winget install qBlank bald

Das Release enthält auch CapView.exe. Sie ist nur für den Umzug einer alten CapView da; neu brauchst du nur qBlank.exe.

Was du brauchst

  • Windows 10 oder 11, 64 Bit.
  • Ein DirectShow-Aufnahmegerät: fast jede Karte, auch per USB. Für Bildschirm oder Fenster nichts.
  • Zum Aufnehmen ffmpeg. qBlank holt es auf Wunsch, siehe Erste Schritte.

Wohin damit

In einen eigenen Ordner, in den du schreiben darfst, etwa C:\Spiele\qBlank. Nicht unter Programme: qBlank legt alles neben sich ab, und dort lässt Windows Programme nicht schreiben.

Neben dem ProgrammWas es ist
qBlank.jsonEinstellungen und Profile
qBlank.logDas Protokoll, nur wenn du es einschaltest
ffmpegffmpegs Bibliotheken, wenn qBlank sie geladen hat

Nichts landet in der Registry, außer der virtuellen Kamera, wenn du sie installierst.

SmartScreen

qBlank ist nicht signiert: Ein Zertifikat kostet jedes Jahr Geld. Beim ersten Start meldet Windows deshalb vielleicht Der Computer wurde durch Windows geschützt. Klick auf Weitere Informationen, dann auf Trotzdem ausführen.

Der ganze Quellcode liegt auf GitHub, für jeden lesbar.

Erste Schritte

  1. qBlank starten und F2 drücken. Unter Quelle → Bildquelle Capture-Karte, Bildschirm oder Fenster wählen.
  2. Dann die Karte unter Videogerät, den Monitor oder Fenster wählen. Das Bild erscheint sofort.
  3. Ton von Bildschirm oder Fenster: Ton → Tonquellen der Aufnahme → Systemton ohne qBlank.
  4. Verknüpfungen: Allgemein → Verknüpfungen legt sie im Startmenü und auf dem Desktop an.
  5. Zum Aufnehmen: Encoder → ffmpeg herunterladen, etwa 57 MB aus den GitHub-Releases von gyan.dev (entpackt 120 MB), per SHA-256 geprüft.
  6. Für OBS, Discord oder den Browser: Aufnahme → Virtuelle Kamera → Kamera installieren. Das fragt einmal nach Administratorrechten.

Alles Weitere steht im Handbuch.

Updates

Einstellungen → Über sucht beim Start nach einer neuen Version, wenn du es lässt, oder mit Jetzt suchen. Herunterladen und installieren ersetzt das Programm. Die alte Version wird beiseitegelegt und beim nächsten Start gelöscht, ein gescheitertes Update macht also nichts kaputt. Einstellungen und Profile bleiben.

Mit winget installiert, geht auch winget upgrade qBlank.

Umzug von CapView

Bis Version 3.7 hieß qBlank CapView. In CapView 3.7 findet Einstellungen → Updates die neue Version von selbst. Den Umzug macht dann die kleine CapView.exe aus jedem Release:

  • Sie lädt qBlank herunter,
  • meldet eine virtuelle Kamera ab, die aus diesem Ordner registriert war,
  • lenkt die Verknüpfungen auf Desktop und im Startmenü auf qBlank um
  • und startet es.

Einstellungen und Profile ziehen mit: Eine CapView.json neben dem Programm wird übernommen.

Entfernen

  1. Virtuelle Kamera installiert? Zuerst Aufnahme → Virtuelle Kamera → Kamera deinstallieren.
  2. Allgemein → Verknüpfungen entfernt die Verknüpfungen.
  3. qBlank schließen und seinen Ordner löschen. Sonst bleibt nichts zurück.

Mit winget installiert, ersetzt winget uninstall qBlank den letzten Schritt.
